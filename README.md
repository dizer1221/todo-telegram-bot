# Telegram-бот "Список задач"

Бот для ведения личного списка задач прямо в Telegram.

## Возможности
- добавление задач
- просмотр списка
- отметка "выполнено"
- удаление задач
- у каждого пользователя свой список (SQLite)

## Технологии
Python, aiogram 3, SQLite

## Запуск
1. Установите зависимости: pip install -r requirements.txt
2. Создайте файл .env по образцу .env.example и вставьте токен от @BotFather
3. Запустите: python bot.py
